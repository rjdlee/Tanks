# Tank Time art

The menu, rotating toy tanks, cream blocks, crates, pits, mines, and wood floor
were generated from the original coordinated Tank Time concept images commissioned
for this game. WebP versions preserve transparency and reduce download size.
No remote asset services are used. The original PNG concepts are retained in the
workspace generated_images folder.

Fredoka is by Milena Brandão and distributed under the SIL Open Font License.
See OFL.txt. It is bundled locally so the game does not depend on a font CDN.
